Install note

Put the SupremeTags.jar in your server plugins folder, restart, then run /tags.

Server setup

Install in three steps

  1. 1Download the latest stable jar from this page.
  2. 2Move it into your server's plugins folder.
  3. 3Restart the server and use /tags to confirm it loaded.
